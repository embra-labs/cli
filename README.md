# Embra CLI

The command-line client for [Embra](https://embra.cloud/), an app hosting platform being built for teams in Vietnam, with Postgres at the heart of the deployment workflow.

**Status: in development.** This repository is reserved for the public CLI. There is no public release or supported installation command yet.

Embra is **preparing closed alpha with manual onboarding by invitation**. Visit the website to review the [current product scope](https://embra.cloud/#trang-thai) or [join the alpha waitlist](https://embra.cloud/#join).

New to Embra? [Start here (Tiếng Việt)](https://github.com/embra-labs/.github/blob/main/docs/start-here.md) for the current scope, alpha signup, and what happens next.

### Roadmap and what you can try

M1 builds the CLI, prebuilt container-image deployment, Postgres, and migration foundations. M2 continues the build, deploy, review, and recovery flow illustrated on the website. Supported capabilities will be confirmed in the invitation.

Today you can run the separate [backfill-demo](https://github.com/embra-labs/backfill-demo) with Docker Compose, or read the [engineering report](https://embra.cloud/engineering/backfill-8m/). This 1,000-row teaching fixture is not an installable Embra CLI or a reproduction of the larger benchmark.

Joining the waitlist and confirming your email do not grant immediate access. The opening date is not set. Before a trial starts, Embra will confirm supported features, limits, costs, access instructions, and how to retrieve your data.

Installation instructions, usage examples, and release notes will be added here when the CLI is available.

Questions about alpha access? Contact [hello@embra.cloud](mailto:hello@embra.cloud).
